# API index

Find an exported symbol, its declared import path, the relevant guide and
its implementation. This index is generated from package manifests and
TypeScript exports, including re-exports.

An indexed symbol is an available entry point, not a promise that every
edge case has a prose example. Start with the linked guide for behaviour
and lifecycle; use your installed declarations for exact signatures.
The index describes the current source tree. Check
[compatibility](./compatibility.md) before using it with an older release.
