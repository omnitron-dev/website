# API index

Find an exported symbol, its declared import path, the relevant guide and
its implementation. This index is generated from package manifests and
TypeScript exports, including re-exports.

An indexed symbol is a declared entry point. An exported type or option does not
prove that a runtime path consumes it, that a backend is wired, or that shutdown
and delivery are automatic. The generated index preserves the source declarations;
behavioral limitations belong in the linked guides. Start with the linked guide for behaviour
and lifecycle; use your installed declarations for exact signatures.
Source links open the exact Omnitron commit used to build this index. Check
[compatibility](./compatibility.md) before using it with an older release.
